# Auto-Reminder (Fahrzeug-Verwaltung)

Web-App (PWA) für iPhone und Desktop: bis zu 10 Fahrzeuge mit FIN, Kennzeichen,
Versicherung, km-Stand, Service-Historie, Wartungsintervallen (Ölwechsel PKW 25.000 km,
Motorrad 5.000 km), TÜV/HU-Erinnerung, Kalender-Erinnerungen (.ics) und JSON-Backup.

Die Daten bleiben lokal im Browser des jeweiligen Geräts.
